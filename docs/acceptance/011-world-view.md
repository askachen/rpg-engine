# 第十一批：S4-01 地圖視窗、提示與轉場

日期：2026-09-16。本批已由使用者回覆「請繼續」確認。以下為當批紀錄；後續四方向面向與逐格動畫驗收見 012-actor-animation.md。

## 變更

- 世界移到獨立 world_surface，由固定 1320×760 視窗裁切；HUD 保持固定，鏡頭逐格跟隨角色並夾住地圖邊界。
- 統一世界格與螢幕座標，避免鏡頭移動後點錯格子；視窗外不啟動尋路。
- 滑鼠指向互動格顯示名稱與外框；條件不足、已拾取、對話／選單／轉場中有一致顯示規則。
- 出口淡出 → 同一 core.act 換圖 → 淡入，各 0.18 秒，期間鎖定 HUD／鍵盤／滑鼠，目的地重新計算鏡頭。
- 既有 furniture.layer=floor 正式進入地面繪製層；驗證器只把 solid 家具算入碰撞集合，與 runtime 一致。霧港工坊恢復大地毯並與桌子、互動格重疊。
- 滑鼠測試等待 transition 完成，沿用相同正常玩法操作；不更動 core 規則與存檔格式。

## 驗證方法與發現

- `python tools/dev.py check --json`：**78 項測試全部通過**，包括既有兩款遊戲通關、存讀檔及跨遊戲隔離。

- 60×32 格大地圖 fixture，以實際滑鼠點擊移動到遠端角落，驗證雙軸鏡頭、座標反算、hover、換圖後鏡頭歸零與輸入恢復。
- 檢查淡出及淡入期間，HUD 與鍵盤都不能修改狀態；測試按實際階段同步，避免固定等待秒數受幀率影響。
- 地毯與 solid 家具重疊的正反例，保持實體碰撞檢查。
- NVIDIA OpenGL 實際渲染器下 camera_failures=[]、harbor_mouse_failures=[]；人工檢查遠端地圖及工坊重疊地毯截圖。
- GPU 檢查發現並修正 surface 的零尺寸邊界導致捲動後整張地圖被裁掉；新增 bounds 及實際像素檢查，不能只以 headless 通關代替畫面驗收。

截圖位於 test-results/camera-far-corner.png、test-results/harbor-workshop.png；日誌與 JUnit 位於各 run 目錄，均為本機驗證產物，不提交到 repo。

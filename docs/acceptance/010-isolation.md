# 第十批驗收：S3-03 跨遊戲資料隔離

日期：2026-09-15。狀態：已由使用者回覆「繼續吧」確認。

## 方法

專項重跑：`python -m pytest tests/test_isolation.py -q`；完整回歸：`python tools/dev.py check --timeout 240 --json`。

新增 tests/isolation_mouse.gd 與 tests/test_isolation.py。使用真正 demo 和 fog_harbor，五次獨立 Godot 程序共用同一個臨時 APPDATA／user:// 目錄，依序執行 demo 建立進度、霧港建立進度、demo 重新載入、霧港重新載入、demo 再次載入。

建立進度透過 Viewport 滑鼠走公開通關情境，點擊設定、音量滑桿、跑步按鈕及存讀檔選單；沒有注入金錢、完成事件、解鎖或已讀資料。逐格 move 由點擊目標的正常尋路取代；買第二個物品時重新點擊櫃台，符合正式 UI 的商店關閉行為。

## 已驗證

- 完整回歸：**76 passed in 127.70s**。suite 已超過舊 120 秒期限，因此 CLI 預設每個非互動子程序期限提高為 240 秒；仍可由 --timeout 覆寫。完整回歸使用相同 240 秒設定通過。

- 第一款已有進度時，第二款仍從空的槽位／解鎖／已讀與預設設定開始。
- demo 使用英文、不同音量、關閉跑步；霧港使用繁中、另一音量、開啟跑步。重啟後確認 profile 與實際 AudioServer 音量、UI 語言／跑步狀態一致。
- 每款分別取得自己的兩張紀念卡與真實對話已讀紀錄。profile 完整相等，兩款已讀 ID 集合不重疊。
- 繼續遊戲、自動槽與兩個不同時段的手動槽只載入目前遊戲的正確狀態。畫廊按鈕顯示並啟用自己的卡片。
- 在臨時測試目錄將對方 slot1 複製到自己的 slot6，模擬誤放檔案：原生讀取拒絕、槽位 UI 停用、目前進度維持不變。
- 比較 JSON 檔案 SHA-256：建立第二遊戲不改第一遊戲；交替載入與拒絕外來存檔都不改任何持久化檔案。
- 專項測試通過，五次 OS 程序均回報 isolation_failures=[]。

## 界線

本批沒有修改共用 engine/；S3 的第二款內容與隔離驗證均使用同一 runtime。全螢幕目前未持久化，完整設定在 S4-07；本批驗證現有持久化設定。拒絕外來存檔以 bool／停用槽位表示，詳細存檔錯誤碼與完整 Schema 仍在 S5。此測試不是存檔抗竄改或安全邊界驗證。

測試為 headless 下的真實 Viewport 輸入，不宣稱本批新增 GPU 畫面驗收。S3-01／02 的實際 NVIDIA 渲染驗收見 009-fog-harbor.md。Godot 本機憑證存放區警告仍存在，SCRIPT ERROR 則會使測試失敗。

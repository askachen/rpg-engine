# 第十二批：S4-01 四方向面向與行走影格

日期：2026-09-16。狀態：已由使用者回覆「請繼續」確認。與第十一批鏡頭、提示、地面分層及轉場合併構成 S4-01。

## 交付

- actor_motion 獨立管理呈現方向與步態時鐘；滑鼠、鍵盤、停止、碰撞及相鄰互動的方向一致。
- avatars.walk 支援四方向影格陣列、fps、idle_frame；兩份正式 Schema 與語意驗證同步更新。
- 霧港主角新增透明四方向三姿勢圖集，原始 PNG、完整 imagegen 提示詞與固定大小的圖集取樣配置全部提交。
- 跑步加快步態；停止／選單／對話／轉場停止動畫，停止後顯示同方向站立影格。新遊戲、讀檔與繼續重設呈現狀態。
- 既有 sprite 格式相容，沒有動畫的其他角色保留舊素材；不改 core 規則、碰撞、存檔格式或劇情條件。

## 驗證

- `python tools/dev.py check --json`：**85 項測試全部通過**，包括兩款故事、鏡頭轉場、存讀檔與跨遊戲隔離。

- 6 個負面資料案例：缺方向、空陣列、非法 fps、idle 越界、未宣告圖片與圖集索引越界。
- 實際滑鼠四方向移動與停止後朝向、連續行走中選取不同影格、相鄰互動時雙方朝向、跑步速度時鐘、撞牆不走路、暫停與舊素材 fallback。
- NVIDIA OpenGL 實際渲染：motion_failures=[]，檢視朝上背面與朝右側面等截圖，角色尺寸符合目前地圖比例。
- headless 通關仍使用相同 core；面向與動畫是呈現狀態，不注入或修改正式遊戲狀態。

## 範圍

目前只有霧港主角新增四方向美術；其他遊戲或角色可按同一格式配置，未重繪全部人物。NPC 移動排程與動態出現仍屬 S4-02。既有逐格位置移動保留，未增加像素級位置插值。生成素材的細微姿勢差異仍可由正式美術替換。完整資料契約見 [角色動畫](../actor-animation.md)。

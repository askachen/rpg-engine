# 第十三批：S4-02 NPC 排程與物件互動

日期：2026-09-17。狀態：已驗證／待使用者確認；S4-01 已由使用者回覆「請繼續」確認。

## 交付

- `visible_when` 控制物件存在；NPC `schedule` 使用依序第一個符合的 AND 條件，支援跨地圖位置及無匹配時消失。
- core 解析目前地圖物件，繪圖、hover、滑鼠／鍵盤互動、商店、碰撞與尋路共用結果。
- `inspect` 提供一般調查與指定物品互動；滑鼠確認、消耗／保留提示、缺物停用、文字換行、一次性／可重複效果。
- 操作效果失敗會還原物品與旗標；排程／旗標操作若使玩家腳下出現阻擋，整次還原。對話提交遇到此情況回探索，允許移動後重試。
- 兩份內容 Schema、公開 walkthrough item 參數、語意檢查與雙語示範內容同步更新。
- 霧港新增告示、鑰匙、置物櫃、條件式便條；瑪拉晚上依便條旗標決定在碼頭或工坊，白天／深夜回原位置。

## 限制

排程是離散換位，沒有 NPC 路線步行演出。驗證器保守禁止不同排程物件共用可能位置，即使条件互斥。指定路線回歸不構成任意內容的全狀態可達性證明。完整背包自由選物、存檔遷移、世界狀態空間探索仍按 S4-09／S5 排程。

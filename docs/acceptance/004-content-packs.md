# 第四批驗收：Manifest 與內容拆檔

日期：2026-09-13。S2-01 已於 2026-09-14 由使用者回覆「繼續吧」確認；S2-05 僅完成入口選擇，仍開發中。

## 交付與驗證

- demo 的地圖、角色、事件、物品、商店、路線、结局、紀念卡及語系拆為來源片段；保留既有 ID 與狀態。
- Python 與 Godot 各有組合載入器，整份 demo 合併結果逐值相同；不包含另寫一套遊戲規則。
- 缺檔、跨檔重複 ID、非法来源路徑、未知版本及 JSON 語法錯誤有錯誤情境。
- 原單檔主題／路線 fixture 繼續可用；既有滑鼠六事件通關、存讀檔與演出測試通過。
- `list`、`validate --game`、`play --game` 及 `check --game` 已加入。theme_preview 是可選擇的紫色主題配置預覽。

命令 `python tools/dev.py check`：36 項測試通過。Manifest／runtime 一致性與 CLI 測試包含於 pytest。圖形呈現本批未改布局，仍以原滑鼠回歸和渲染 smoke 驗證整合。

## 邊界

本批沒有完成正式 Schema、建立新遊戲指令、任意內容通關測試或發行建置，S2 尚未整階段完成。主題預覽不算 S3 第二款遊戲。`check --game` 會清楚印出測試範圍，不能當作任意任務都不會卡關的證明。

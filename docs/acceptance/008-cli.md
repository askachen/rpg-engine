## 範圍與限制

S2 build 是需要 Godot 的原始專案封裝，不是 Windows executable 或完整 Python SDK。S6 仍需匯出範本、exe、解析度與發行驗收。自訂資源的外部依賴須列入 assets，不自動遞迴收集。每次測試資料隔離，但同 checkout 的匯入快取仍共用，並行 CI 應使用獨立 checkout。

指定路線通過不等於所有選項組合不會卡關。Godot 本機憑證存放區警告仍存在，沒有把 SCRIPT ERROR 當作成功。README 已明列未完成能力及正式授權文件尚缺。

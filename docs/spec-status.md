## 明確差異

- demo 目前四張地圖、六個事件，並非規格目標的 15–30 分鐘正式內容；咖啡事件是短篇功能示範。
- 存檔仍限定事件外，沒有新增演出中存檔需求。
- 已讀判定含語言及實際譯文。v0.6 將此已實作行為寫明；文字 ID 本身保持穩定。
- 圖片／表情指定欄位不等於完成正式素材示範；圖片生成額度失敗未改變必要功能範圍。
- Live2D 仍需實測或明確範圍決策，不以靜態圖片宣稱支援。
- 測試 fixture 不算第二款遊戲；指定通關測試不證明所有選擇均可達結局。

README 為啟動與當前功能摘要；有歷史驗收報告時，其測試數字代表當時結果，而非最新測試總數。

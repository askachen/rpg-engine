- 新增 S5 對應 Homestay 團隊回報：S5-01 數值／比較／交易／狀態 UI 及基本存讀檔已實作，見 [數值契約](numeric-state.md)。其餘日期／位置條件／事件入口、P1／P2 尚未實作，見 [详细計畫](s5-content-capabilities.md)。原 S5–S7 順延為 S6–S8；歷史驗收紀錄保留當時編號。

- 存檔仍限定事件外，沒有新增演出中存檔需求。
- 已讀判定含語言及實際譯文。v0.6 將此已實作行為寫明；文字 ID 本身保持穩定。
- S4-04 已加入霧港背景、風景 CG 與瑪拉表情／眨眼實例；其他角色仍可使用既有靜態素材。
- Live2D 已依使用者要求暫緩；已有離線準備檢查，尚未支援播放。見 [技術驗證](live2d.md)，不以靜態圖片或準備檢查宣稱支援。

README 為啟動與當前功能摘要；有歷史驗收報告時，其測試數字代表當時結果，而非最新測試總數。

# 音訊與玩家設定（S4-07）

設定可從開頭選單或遊戲選單進入，全程使用滑鼠；內容超出視窗時可滾動。調整後自動儲存到該遊戲自己的 profile，與單局存檔分離。`player_settings.gd` 統一預設值、範圍、音訊 bus 與視窗套用；舊 profile 缺少欄位時補預設，不清除已讀或解鎖資料。

| 項目 | 範圍／預設 | 行為 |
| --- | --- | --- |
| 主音量 volume | 0–1／0.8 | Master，控制全部聲音，包含影片 |
| 音樂 music_volume | 0–1／1 | Music → Master |
| 音效 sfx_volume | 0–1／1 | SFX → Master |
| 語音 voice_volume | 0–1／1 | Voice → Master |
| 對話字級 text_size | 22–36／28 | 對話正文；設定頁有預覽，非所有 UI 縮放 |
| 打字速度 text_speed | 10–100／35 | 每秒顯示字數；按下一步仍可立即顯示全文 |
| 自動等待 auto_delay | 0.5–5 秒／1.4 | 全文顯示後等待；同時必須等語音停止 |
| 視窗 resolution | 1280×720、1600×900、1920×1080、2560×1440／1920×1080 | 按鈕循環選擇；超出桌面時等比例縮小並保留標題列空間 |
| fullscreen | false | 使用螢幕尺寸；返回視窗套用選定解析度 |

音量零會 mute 對應 bus，其他分組不受影響；最終仍乘上 Master 音量。音樂／音效保留既有每個播放器的基準音量。重複套用不會重複建立 bus；切換遊戲會套用新遊戲 profile。

解析度是視窗尺寸偏好，不改地圖或 1920×1080 設計座標，也不改螢幕系統解析度。偏好大於可用桌面时，保留原偏好但實際視窗縮小。headless 不呼叫顯示裝置 API。全解析度、DPI、最低硬體矩陣仍在 S7。

## 語音內容

對話 sequence 的 line 可加入一個 `voice` 路徑：

```json
{
  "id": "greeting",
  "speaker": "mara",
  "text": "greeting_text",
  "voice": "res://games/my_game/assets/greeting.wav"
}
```

素材必須在 assets 登記，支援現有音訊格式 WAV／OGG／MP3，沿用原生素材載入檢查。voice 可與圖片、bgm、sfx 同句使用，不可與 video 混用。每句開始播放一次，換句、跳過、取消或關閉對話時停止；對話紀錄／隱藏文字框會暫停，返回後恢復。自動播放不切斷語音，手動下一步或已讀快轉仍可跳過。

影片是含音軌的單一串流，仍走 Master 與影片自己的滑桿，不拆成音樂／語音。語音目前是單一路徑，不提供依語言自動切換音軌或配音生成；可由作者在不同內容中指定素材。

## 驗證邊界

`tests/settings_flow.gd` 實際注入滑鼠操作各滑桿、滾動、全螢幕與解析度，再驗證獨立 bus、打字／自動等待及語音生命週期；另一個 Godot 程序重讀同一 profile，確認重新啟動後恢復並套用設定。語音播放測試使用既有合成音訊作為 fixture，不宣稱範例故事已有真人配音。

測試檢查播放器與 mixer 的值，未量測喇叭輸出。長篇文字在各字級的內容排版仍需作者驗收；此批不包含任意長文自動分頁。設定檔備份與寫入失敗復原仍在 S6。
